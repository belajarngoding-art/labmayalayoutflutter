# Modul 5 — Layout Flutter

## Tujuan pembelajaran
Siswa dapat menjelaskan fungsi Container, Row, Column, mainAxisAlignment, crossAxisAlignment, padding, dan margin; serta membuat layout sederhana dengan Dart.

## Container
Container mengatur ukuran, padding, margin, warna, dan dekorasi sebuah area.

## Row dan Column
- Row menyusun anak widget secara horizontal.
- Column menyusun anak widget secara vertikal.
- mainAxisAlignment mengatur distribusi anak pada sumbu utama.
- crossAxisAlignment mengatur perataan anak pada sumbu silang.

## Praktik
Buat kartu profil siswa dengan avatar, nama, kelas, dan keahlian. Gunakan Container, Column, Row, dan SizedBox.
